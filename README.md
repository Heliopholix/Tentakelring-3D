# Tentakelring 3D – Vorschau

Lokales, versioniertes Parametermodell für den ersten 3D-Entwurf des Dagon-Farbrings.

## Start
Öffne `index.html` direkt in einem aktuellen Browser. Die Vorschau läuft ohne Server und externe Bibliotheken.

## Aktuelle Annahmen (v0.1)
- Referenzring: Außen-Ø 27,85 mm, Rand innen Ø 25,30 mm, Grundöffnung Ø 14,90 mm
- Gesamthöhe 4,25 mm; Grundplatte 1,35 mm; aufgesetzter Rand 2,90 mm
- Zwei Tentakel, Ø 2,50 mm, Start auf halber Randhöhe
- Gleichläufig, 180° phasenversetzt, je eine Umdrehung
- Standardsteigung 3,00 mm/Umdrehung
- Verjüngung beginnt standardmäßig bei 75 % der Umdrehung
- Eine Umdrehung endet bei z = 5,80 mm; das liegt 1,55 mm über der Ringoberkante

Die Referenzringgeometrie ist vereinfacht. Die Vorschau zeigt die parametrisierte Bahn und einen runden Querschnitt. Es ist noch kein druckfertiges Netz und noch kein 3MF.

## Git
Dieses Verzeichnis ist ein eigenständiges lokales Git-Repository. Änderungen an Parametern und Geometrie lassen sich als Versionen speichern.

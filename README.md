# Tentakelring 3D – Vorschau

Parametrische Vorschau für den Tentakel-Farbring einer *Death May Die*-Miniatur von Dagon.

## Start

Öffne `index.html` in einem aktuellen Browser. Die interaktive Vorschau läuft ohne Server oder externe Bibliotheken. Ziehen dreht das Modell, das Mausrad zoomt.

## Aktueller Entwurf

- Referenzring: Außen-Ø 27,85 mm, Rand innen Ø 25,30 mm, Grundöffnung Ø 14,90 mm
- Gesamthöhe 4,25 mm; Grundplatte 1,35 mm; Randhöhe 2,90 mm
- Zwei Tentakel mit rundem Querschnitt, standardmäßig Ø 2,50 mm
- Gleichläufige Helixbahnen, 180° versetzt, eine Umdrehung
- Standardsteigung 3,00 mm pro Umdrehung; Verjüngung ab 75 %
- Tentakelkörper als geschlossene, glatt schattierte Volumenkörper mit zulaufenden Spitzen
- Saugnäpfe optional einblendbar

Die Ringgeometrie ist eine vereinfachte Referenz. Die Vorschau ist noch kein druckfertiges Netz und enthält noch keinen 3MF-Export.

## Versionierung

Dieses Projekt wird im privaten GitHub-Repository [Heliopholix/Tentakelring-3D](https://github.com/Heliopholix/Tentakelring-3D) versioniert. Entwicklungsstände und Geometrieänderungen werden über Git-Commits festgehalten.
